# Contributing

Thanks for helping improve Paste Scraper Builder.

## Local Setup

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run install-hooks`.
4. Start the app with `npm run dev`.

## Checks

Run these before pushing:

```sh
npm run fmt:check
npm run lint
npm test
npm run build
npm run smoke
```

Use Conventional Commits for commit messages, for example `feat: add selector preview`.
