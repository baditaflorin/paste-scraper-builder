# Security Policy

## Supported Versions

The latest tagged release is supported.

## Reporting a Vulnerability

Please report vulnerabilities by emailing Florin Badita at security@badita.org.

Do not open public issues for suspected vulnerabilities.

## Scope

Paste Scraper Builder is a client-side GitHub Pages app. It does not run a hosted scraping service and does not need runtime secrets. Pasted HTML remains in the user's browser unless they choose to export or copy it.
