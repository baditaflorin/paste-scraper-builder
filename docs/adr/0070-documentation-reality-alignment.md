# 0070 Documentation Reality Alignment

## Status

Accepted.

## Context

README drift is a usability bug when people land on the repo before the live app.

## Decision

README feature claims must be backed by shipped controls and at least one test or audit row. Unsupported capabilities go in limitations, not roadmap-flavored copy.

## Consequences

The README will describe auto-inference, upload/drop/clipboard, JSON state, share links, exports, and limitations.

## Alternatives Considered

Leaving README as a v1 description was rejected because it under-describes the app and hides real workflows.
